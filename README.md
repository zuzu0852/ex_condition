# 瞬間ジャッジ!撮影条件

患者さんの全身イラスト(正面・側面)を見て、一般撮影の mAs を「下げる・そのまま・上げる」で瞬時に判断するスマホ向けゲームです。
部位ごとの「編」(膝・股関節・胸部・腹部・腰椎・頸椎)を各20問、クリアタイムを競います。

- 公開URL: https://zuzu0852.github.io/ex_condition/
- `index.html` … ゲーム本体
- `apps_script.gs` … スコア集計用 Google Apps Script(スプレッドシートの `plays` / `responses` シートに記録)

個人情報は集めません(端末ごとの匿名ID+任意のニックネーム)。
正解ルール(体厚差 ±1cm 以内は「そのまま」、4cm で線量約2倍)と各編の基準条件は仮の値です。
生成AIで作った全身画像に差し替える場合は、`index.html` の `PHOTO_SETS` に登録します。
